# Security

Shellium stores SSH host lists and passwords, so security reports are welcome.

## Reporting a vulnerability

Please report it privately through GitHub: **Security › Report a vulnerability** on this repository
(a private security advisory). Do not open a public issue for it.

Include what is affected, how to reproduce it and the Shellium version (Help › About).

## What to expect

Shellium is a personal, volunteer project. Reports are read and fixed on a best-effort basis: there
is no promised response time, no fix deadline, no bug bounty and no support agreement of any kind.
